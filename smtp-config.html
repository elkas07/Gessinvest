Configuration SMTP - Emails de confirmation

Configuration des emails de confirmation

Problème actuel : Les utilisateurs ne reçoivent pas d'email de confirmation après inscription.

Solution : Configurer SMTP dans Supabase

Pour que vos utilisateurs reçoivent des emails de confirmation, vous devez configurer un service SMTP personnalisé dans les paramètres Supabase.

1

Accédez aux paramètres d'email Supabase

Dans votre projet Supabase, allez dans Authentication → Settings.

Faites défiler jusqu'à la section Email Templates.

2

Remplissez les informations d'expéditeur

Avant d'activer SMTP, vous devez configurer :

Sender Email
contact@gessinvest.com

L'adresse email qui enverra les confirmations

Sender Name
GESSINVEST

Le nom qui apparaîtra dans l'email

3

Activez et configurez SMTP

Cliquez sur "Enable Custom SMTP" et configurez avec les paramètres de votre fournisseur email.

Gmail (Recommandé)

Serveur SMTP : smtp.gmail.com

Port : 587 (TLS)

Utilisez un mot de passe d'application

Guide Gmail
OVH

Serveur SMTP : ssl0.ovh.net

Port : 587 (TLS)

Guide OVH
Hostinger

Serveur SMTP : smtp.hostinger.com

Port : 587 (TLS)

Guide Hostinger
4

Paramètres SMTP à remplir

Une fois que vous avez choisi un service, configurez ces paramètres dans Supabase :

Hôte SMTP
smtp.gmail.com (pour Gmail)
Port
587 (recommandé pour TLS)
Nom d'utilisateur
votre.email@gmail.com
Mot de passe
Mot de passe d'application (Gmail)
5

Testez la configuration

Après avoir sauvegardé les paramètres, testez l'envoi d'email en créant un nouveau compte de test.

Comment tester :

  1. Allez sur votre site GESSINVEST
  2. Cliquez sur "Créer mon compte"
  3. Remplissez le formulaire d'inscription
  4. Vérifiez si l'email de confirmation arrive

Conseil : Pour Gmail, vous devez activer la validation en 2 étapes et créer un "mot de passe d'application" spécifique pour SMTP.

Dépannage - Problèmes courants

Je ne reçois pas les emails de test

  1. Vérifiez vos paramètres SMTP (surtout le mot de passe d'application pour Gmail)
  2. Assurez-vous que le port 587 n'est pas bloqué
  3. Vérifiez les logs de Supabase pour des erreurs d'envoi d'email

Je ne trouve pas l'option SMTP dans Supabase

L'option se trouve dans : Authentication → Settings → Email Templates

Faites défiler jusqu'en bas de la page pour trouver "Custom SMTP"

Erreurs d'authentification

Pour Gmail, n'utilisez pas votre mot de passe normal mais un mot de passe d'application :

  1. Allez dans les paramètres de sécurité Google
  2. Activez la validation en 2 étapes
  3. Générez un mot de passe d'application pour SMTP
  4. Utilisez ce mot de passe dans Supabase
